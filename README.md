# Java-Repeticao

Coleção de exercícios Java sobre laços, fatorial, tabuada, média, arrays e matrizes.

## Funcionalidades verificadas

- Exercícios de repetição.
- Fatorial, paridade e tabuada.
- Arrays, consoantes e matriz multidimensional.

## Operação e arquitetura verificadas

Classes independentes com main nos pacotes com.NunesDev.Loops e com.NunesDev.Arrays. Arquivos out são resultados antigos de compilação.

Arquivos principais: `src/com/NunesDev/Loops/NotaIdade.java`, `src/com/NunesDev/Loops/Fatorial.java`, `src/com/NunesDev/Arrays/Consoantes.java`.

### Requisitos e execução

JDK com javac; console interativo.

```text
javac -encoding UTF-8 -d build src/com/NunesDev/Loops/*.java src/com/NunesDev/Arrays/*.java
java -cp build com.NunesDev.Loops.NotaIdade
```
